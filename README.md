# 🌤️ React Weather App

A simple, elegant, and fast **Weather App** built using **React.js** and **Framer Motion**.  
It fetches real-time weather data from the **Open-Meteo API** and displays it in an animated weather card.

---

## 🚀 Features

- 🌍 Real-time weather data (temperature, wind speed, condition)
- ⚡ Fetches data from the [Open-Meteo API](https://open-meteo.com/)
- 🎞️ Smooth animations using **Framer Motion**
- 💻 Built with pure **React.js** (no Tailwind)
- 📱 Responsive and clean user interface

---

## 🛠️ Technologies Used

- **React.js** — Frontend framework  
- **Axios** — For making API requests  
- **Framer Motion** — For animations  
- **Open-Meteo API** — For weather data  

---

## 📦 Installation & Setup

Follow these steps to run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/ajitGandhi095/weather-app.git

2. Navigate into the project folder:
     cd weather-app

3. Install dependencies:
     npm install

4. Start the development server:
     npm start

5. Open your browser and go to:
     http://localhost:3000

6. This app uses Open-Meteo API for fetching weather data.
     https://api.open-meteo.com/v1/forecast?latitude=17.3850&longitude=78.4867&current_weather=true
